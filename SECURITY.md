# Security policy

FLACker reads local files that may be malformed (FLAC metadata, images, playlists, lyrics). Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository.

Include the affected version, the Android version, a description and, when possible, a minimal synthetic file that reproduces the problem. Do not send music, lyrics or private documents.

The app has no internet permission and never downloads code. Install updates only from this repository's releases, signed with the certificate listed in the README.
